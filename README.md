# Pestora Shield HTML Template

A responsive, accessible pest-control and fumigation service website built with semantic HTML, custom CSS and vanilla JavaScript.

## Start

Open `pages/homepage1.html` or `pages/homepage2.html` in a browser. No build step is required.

## Included

- Eleven customer-facing pages with exact requested section counts
- Shared responsive header and footer
- Light/dark theme persistence
- RTL stylesheet
- Accessible dropdowns and FAQ accordions
- Demo client-side form validation

## Before production

Replace all placeholder contact details, canonical URLs, credentials, testimonials and legal links. Verify the demo pricing before launch. Connect forms and authentication to a secure backend. Generated local WebP photography is included and can be replaced with licensed brand photography.

See `documentation/index.html` for more details.
